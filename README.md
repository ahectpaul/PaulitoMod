## PaulitoMod
A lightweight Fabric utility mod for Minecraft 1.20.1 designed to improve combat visibility, player awareness, and survival feedback in custom server environments.

PaulitoMod focuses on delivering clear, efficient, and server-side gameplay information without adding unnecessary client-side complexity. It is built for private or community servers that want a more informative and polished experience while keeping the implementation lightweight and easy to maintain.

## Features
Hostile mob kill tracking with detailed combat messages
Weapon and player identification for clearer event logs
Custom item name support for more readable kill feed output
Kill streak monitoring and reward-based progression
Player health awareness and near-death tracking
Dimension tracking with low-overhead state updates
Improved tab list information, including health, dimension, and coordinates
Flexible configuration for rewards, thresholds, and toggles
Requirements
Minecraft 1.20.1
Fabric Loader
Java 17
Installation
Download the latest release from the Releases page.
Place the .jar file in your server’s mods folder.
Start the server with Fabric installed.
If the mod generates its config file, adjust settings as needed in the config directory.
Configuration
The mod includes automatic configuration generation where relevant settings can be adjusted without modifying the source code directly. This allows server owners to tune rewards, streak thresholds, and feature toggles more easily.

## Usage
This mod is intended to improve server-side gameplay feedback for survival-focused environments. It helps administrators and players better monitor combat events, player status, and progression while maintaining efficient resource usage.
